# Rätsel-Nahansichten – Bildquellen

Herkunft: Asset-Paket `im-zeichen-der-wende-assets-final` (Ordner 01–11 und `production-transparent/`).

- Die Ausschnitte aus der großen Asset-Tafel waren nur ca. 400 px breit. Sie wurden mit Real-ESRGAN
  (Modell „x4plus anime 6B“, lokal auf der CPU gerechnet) vierfach vergrößert und danach zugeschnitten.
  So bleiben Konturen scharf, feine Details kommen aber nicht hinzu.
- `production-transparent/` hat Vorrang: Chronistin, Chi-Rho-Schild, Siegelstempel, Siegelmedaillons.
- Alle Dateien sind WebP mit Transparenz (iPad ab iOS 14).
- Texte sind nirgends eingebrannt, außer den gemalten Feldnamen im Mosaik – diese werden im Spiel von
  HTML-Schildern überdeckt.
